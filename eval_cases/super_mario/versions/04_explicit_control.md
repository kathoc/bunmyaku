# スーパーマリオとは何だったのか？

穴に落ちた。走って、跳んで、向こう岸に少し届かなかった。そんな場面を一つ思い浮かべてほしい。まだ十分に反省していなくても、届かなかった距離を見れば、次は跳ぶ位置を変えようと思える。

今度はもう少し先で跳ぶ。さっきより縁に近づくのは怖いが、落ちた場所は見えている。変えるのは、ボタンを押す位置だけだ。届くかどうかは、押すまで分からない。

この場面では、言葉で説明しなくても画面が次の操作の手がかりを与えている。

「跳ぶのが早すぎました」とは言わない。けれど、穴の幅と向こう岸、それから届かなかった距離が画面に残っている。全部を説明されなくても、次に試すことは浮かぶ。さっきの失敗を思い出すうちに、もう次の操作を考えている。

跳び方を横から教えてもらえば、もっと早く進めるかもしれない。ただ、言われた場所で押して越えた穴と、自分で位置を変えて越えた穴は、同じ一つでも少し違う。後者には、自分の見当が当たった感触がある。早く進むこととは別に、自分で確かめる面白さがある。

もちろん、落ちれば誰でも次の手を思いつくわけではない。どこが違ったか見えないまま同じ失敗を重ねるなら、言葉による説明がないことは不親切になる。穴の手前で立ち尽くす人にまで、「自分で考えるのが楽しいでしょう」とは言えない。

それでも、失敗の理由が少し見えたとき、人は説明を聞き終えるより先に動きたくなることがある。マリオの穴越えには、その順序を考える手がかりがある。理解してから操作するだけでなく、操作しようとして理解が動き出す。

向こう岸に着くと、今まで気にしていた穴から次の足場へ注意が移るかもしれない。一つの成功を区切りにして、次の行動へ進むところにも、この遊びの面白さがある。
