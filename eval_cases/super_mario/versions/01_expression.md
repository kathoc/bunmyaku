# スーパーマリオとは何だったのか？

スーパーマリオの面白さは、走って跳ぶうちに、次の一手が見えてくるところにある。操作の手触り、失敗からの学習、自分で進めたという感覚。この三つから考えてみたい。

まず、押したボタンと画面の動きがつながっている。穴の手前で跳ぶ。届かなければ、もう少し先まで走ってみる。操作は少なくても、変えられることはある。

次に、失敗が手がかりになる。穴に落ちたとき、早く跳びすぎたのか、勢いが足りなかったのかを考える。次の挑戦では、そのどちらかを変える。うまく越えれば、予想が一つ確かめられる。

さらに、自分で進み方を選べる。同じ足場でも、立ち止まってから渡るのと、続けて跳ぶのとでは気分が違う。道は用意されていても、どう通るかには手が入る。

一方で、失敗が続けば疲れる。どこを直せばよいか分からないまま落ち続けると、もう一度試す気持ちは薄れる。慣れた人が簡単だと感じる場所でも、初めての人にはそうとは限らない。

スーパーマリオは、小さな操作から試す余地を作るゲームだった。失敗して、少し変えて、先へ進む。その繰り返しを自分の手で確かめられることに、私は面白さを感じる。
