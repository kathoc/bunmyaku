# スーパーマリオとは何だったのか？

発売から40年が過ぎた今、どういうわけか、スーパーマリオブラザーズについて考えている。1985年、任天堂がファミリーコンピュータ向けに発売したアクションゲームだ。走って、跳んで、敵をかわしながら先へ進む。あのゲームである。

いま気になっているのは、穴に落ちたあとのことである。失敗したのに、もう一度やりたくなる。そんなの当たり前だ、と言われそうだが、ゲームを遊ぶ時間のかなりの部分は、この当たり前に支えられていたのではないか。

たとえば、穴に落ちた。走って、跳んで、向こう岸に少し届かなかった。まだ反省もしていないのに、次をやる気になっている。

今度はもう少し先で跳ぶ。さっきより縁に近づくのは怖いが、落ちた場所は見えている。変えるのは、ボタンを押す位置だけだ。届くかどうかは、押すまで分からない。

マリオの親切さは、ここではずいぶん無口だ。

「跳ぶのが早すぎました」とは言わない。けれど、穴の幅と向こう岸、それから届かなかった距離が画面に残っている。全部を説明されなくても、次に試すことは浮かぶ。さっきの失敗を思い出すうちに、もう次の操作を考えている。

跳び方を横から教えてもらえば、もっと早く進めるかもしれない。ただ、言われた場所で押して越えた穴と、自分で位置を変えて越えた穴は、同じ一つでも少し違う。後者には、自分の見当が当たった感触がある。私は攻略としては何の得にもならない、この遠回りのほうが気になる。

もちろん、落ちれば誰でも次の手を思いつくわけではない。どこが違ったか見えないまま同じ失敗を重ねるなら、無口さはただの不親切になる。穴の手前で立ち尽くす人にまで、「自分で考えるのが楽しいでしょう」とは言えない。

それでも、失敗の理由が少し見えたとき、人は説明を聞き終えるより先に動きたくなることがある。マリオの穴越えには、その順序を考える手がかりがある。理解してから操作するだけでなく、操作しようとして理解が動き出す。

では、向こう岸に着いたら、ちゃんと喜べばいい。さっきまであんなに気にしていた穴なのに、もう次の足場を見ているかもしれない。その薄情さもちょっと好きだ。
