# スーパーマリオとは何だったのか？

スーパーマリオは、失敗したあとに「次はこうしよう」と思わせる遊びだった。少なくとも、穴を跳び越える場面からはそう考えられる。落ちた場所と、ボタンを押した瞬間。その二つが、次に変えてみることを教えてくれる。

たとえば、穴の手前で早く跳びすぎたとする。次は踏み切る位置を少し先へずらす。それでも届かなければ、手前から走ってみる。ここで面白いのは、成功する前から自分なりの見当がつくことだ。答えを知らなくても、確かめることはできる。

同じ穴を越えるにしても、言われたとおりにボタンを押したときと、自分の予想が当たったときとでは、成功の意味が違う。後者には「今の跳び方でよかった」という手応えが残る。用意された道なのに、自分で先へ進めた気がするのは、この小さな判断が挟まるからだろう。

ただし、落ちた理由が見えなければ話は変わる。押す時機を変えても結果の違いをつかめない人には、同じ場所のやり直しが続くだけだ。失敗そのものが学びになるわけではない。違いを感じ取れ、もう一度試せることが必要になる。

だから、私がマリオから考えたいのは、難しさの量よりも、失敗のあとに何が残るかだ。届かなかった距離が見え、次に試す手が浮かぶ。穴を一つ越える面白さは、その短い見通しの中にある。
