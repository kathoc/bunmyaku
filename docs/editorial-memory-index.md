# 編集判断の索引

- [取捨選択と内声のリズム](editorial-memory.md): 生成単位と表示段落を分け、採否と損失を記録する。長さの分散を品質目標にしない。
- [意味の足場と記事全体からの選択](editorial-meaning-spec.md): 同義反復を一律に落とさず、意味の依存関係・削除の損失・別案を比較する。
- 標準文体: 指定のない新規執筆は「です・ます」調。明示指定と既存文体の保持を優先する（editorial-memory.md）。
- 敬体の基調と文末の単調さ: editorial-memory.md「敬体を全ての文の語尾にしない」、resources/editorial-register.md。
