# ローカル文書から日本語の比較基準を作る

## 目的と入力

txt・md・jsonlの文書をSQLiteへ保存し、ジャンルごとの文字・文・表現の統計を出力する。対象は手元で利用権限を確認した文書。自作サンプルは動作確認用であり、人間一般の文章を代表しない。

## 実装する範囲

prompts/01から12の順に、構成、DB、投入、解析、表現抽出、プロファイル、比較、評価、時系列差分、統合CLI、品質確認、将来コネクタの設計を実施する。外部サービスへの接続とWeb UIは対象外。

DB操作はdb.pyに集約する。処理単位をrun_idで追跡し、各runの文・token・表現・指標を保存する。本文ハッシュはUTF-8文字列のSHA-256。同文の異なるメタデータは上書きしない。

Sudachiがない場合は文字・文の指標のみを計測し、形態素由来の統計は利用不能と示す。tokenがない状態を低頻度と解釈しない。解析器と辞書のバージョンはrunに保存する。

時系列比較は --from A --to B に対して [A-(B-A), A) と [A, B) の等長期間を比較する。公開日時を優先し、ない場合は収集日時を使う。日時はUTCに統一する。

## 完了条件

仮想環境へインストール後、python -m jlangbase analyze samples/ --profile magazine --out output/ が成功し、profile.jsonとreport.mdを生成する。各段階のpytestと、CLIを別プロセスで動かす統合確認が通る。再投入で文書が増えず、同じコーパスと解析器で統計が再現する。

比較・評価・差分は根拠となる件数と指標内訳を持つ。重みと状態判定の閾値はJSON設定で変更できる。未計測の指標はnullと理由を持ち、総合距離は利用可能な指標だけで重みを再正規化する。

## 追加要件: 表現と文章構成の変化を残す

固定テーマは「スーパーマリオとは何だったのか？」。初稿、表現改稿、構成改稿の3版を保存する。paragraph_count、heading_count、見出し階層の飛び、段落長、段落内文数、冒頭・末尾の分量比率を観測する。主張の位置、具体例の役割、段落の接続、限定、結論は本文中のevidenceとconfidenceを持つ注釈として残す。

record-experimentは別テーマにも使える。manifest内の各版を同一解析器・重み・基準コーパスで評価し、本文コピーとハッシュ、プロファイル、全文の集計値、段落構造、注釈を日時別フォルダに保持する。版の追加や再計測で過去の記録を上書きしない。

統計の再現性は生成日時などの実行メタデータを除く。初稿は比較用に意図して作った文であり、基準文もAI生成であることを明示する。距離の縮小を、人間らしさや構成の改善と同一視しない。

## 完了時の対応関係

01〜10はsrc/jlangbaseとtestsで実装する。11はpytest、CLIによる実行、静的な構文確認で検証し、結果をdocs/decisions.mdに残す。12はdocs/connectors.mdに共通インターフェースと保存方針を定義し、実接続は行わない。

文書投入と解析はローカルCLI専用であり、常駐WebサーバやDBサーバは不要。追加のWeb配信要件は発生していない。
