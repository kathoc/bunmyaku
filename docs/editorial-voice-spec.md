# 次段階: 語り手の具体性と、未解決の判断

## 起点

2026-09-08、ユーザー評価は「30点くらい」。前回の敬体と常体の調整後も、読みやすさと人間特有の生々しさが不足すると指摘された。これは当該原稿への主観評価であり、ベンチマークの測定値ではない。

## 原因仮説

文末の単調さは一部にすぎない。改稿では短い断片や対比を増やし、説明を抽象的な決め文にまとめた。一方、何を試し、どの判断が外れ、どこで困ったかの具体性が薄い。語尾を散らすことを人間らしさの代用にした可能性がある。仮説であり、読者評価による確定は未了。

## 比較する案

- 実際の指摘と改稿の経緯を残す: 効果見込みは高い、実装難度は低い。採用。
- 評価語を具体的な文と読解上の問題へ戻す: 効果見込みは高い、判断難度は中。採用。
- 著者の体験を追加で尋ねる: 素材がなければ有効。今回の冒頭は会話にある事実で試す。
- 不器用な文や俗語を増やす: 表面上の演出になりやすい。不採用。
- 全文を再生成する: 改善の原因が見えにくい。まず冒頭の比較稿に限定。
- 文献を増やす: 理論の補助にはなるが、著者の体験の代わりにはならない。今回の指摘への初手にはしない。

## 仕様

editorial-voice.mdを編集とスキルの入口へ接続する。指示層の変更であり、モデル学習や自動的な事実検証を実装したとは扱わない。
語りの素材は利用者が述べた出来事・引用・判断から取る。感覚、場面、動機を捏造しない。説明の理解可能性を先に守り、語りの粗さを目的にしない。
残す理由と削る理由を判断する際、抽象的なまとめより出来事や判断の変更を優先する選択肢を持たせる。単に具体物を足すのではなく、主題に必要なものを選ぶ。
